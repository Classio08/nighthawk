# NIGHTHAWK — Visual Asset Review Checklist

Use this for every new operator, weapon, environment material or map prop before it is considered production-ready.

## Provenance

- [ ] Source file, creator and exact source URL recorded.
- [ ] Licence version and commercial redistribution permission checked.
- [ ] Original photo consent/release recorded where a person or private property is identifiable.
- [ ] No logos, watermarks, private information or unlicensed third-party artwork.
- [ ] Runtime asset and editable source are stored separately.

## Visual quality

- [ ] Fits realistic modern tactical art direction and the fictional NIGHTHAWK identity.
- [ ] Scale checked against a 1.8 m reference operator and current weapon dimensions.
- [ ] Materials respond plausibly to daylight, shade, night, rain and fog.
- [ ] No obvious UV seams, stretched texels, texture repetition or baked directional shadows.
- [ ] Face identity and silhouette match the approved character reference without inventing unsupported biography.
- [ ] Equipment does not clip through body or weapon animations.

## Technical quality

- [ ] GLB/glTF imports without warnings.
- [ ] Correct material slots, texture colour spaces and normal-map orientation.
- [ ] Pivot, orientation, scale and socket names are consistent.
- [ ] Collision proxy is separate from visual mesh.
- [ ] LODs and distance culling are present where needed.
- [ ] Asset loads asynchronously and has a fallback.
- [ ] Performance impact measured on minimum-tier hardware.

## Owner acceptance

- [ ] Owner reviewed the asset in the game, not only in a render.
- [ ] Approved / changes requested / rejected recorded with date and asset version.
