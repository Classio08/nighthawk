# AI-generated NIGHTHAWK concept references

These small JPEGs are reference previews of AI-generated operator concept sheets retrieved from the earlier NIGHTHAWK project conversations.

They are **not production game assets**:
- not rigged or animated character models;
- not licensed third-party source assets;
- not approved faction insignia, uniforms, real-world unit marks or final character canon;
- not intended to be used as textures, UI portraits or in-game billboards.

The generated artwork may contain fake words, malformed badges, inconsistent equipment, inaccurate anatomy and visual artefacts. Use it to discuss silhouettes, outfit direction, palette, squad composition and cinematic mood only. Production assets must be redrawn or generated from an approved brief, reviewed for accuracy, and logged in ASSETS.md before runtime use.

The original generated images remain in the project conversation. These 384-pixel JPEGs are compressed repository previews; they are not substitutes for the source-resolution images.
