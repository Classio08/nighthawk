# Operator Portraits

These are the real-photo portraits for the 8 Nighthawk operators.
Optimized to 512x512 JPG for web use (select screen, HUD, kill feed, loading).

## Mapping (confirmed from user photos)

| File | Operator ID | Notes |
|------|-------------|-------|
| roms.jpg / roms-alt.jpg | roms | Roms (Assault / Flex) - sunglasses versions preferred for tactical look |
| cleiseis.jpg / cleiseis-alt.jpg | cleiseis | Cleiseis (Support / Tactical) |
| douglas.jpg | douglas | Douglas (Combat Medic) |
| maetja.jpg | maetja | Maetja (Hacker) |
| rampol.jpg | rampol | Rampol (Breacher / Heavy) |
| shadow.jpg | shadow | Shadow (Infiltrator) |

Still missing high-quality portraits for: Navy Blue, Cliffhanger (use placeholders or generate stylized later).

## Usage in game
- Load via `new THREE.TextureLoader().load('/assets/portraits/roms.jpg')` or put in `public/portraits/` for Vite.
- Prefer the concept art sheet for full-body tactical reference: `../ui/operators-concept-sheet.png`
