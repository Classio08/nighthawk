# Textures

Place seamless PBR or simple textures here.

Recommended free CC0 sources:
- ambientCG.com (Ground087, Ground064 for desert)
- polyhaven.com (rocks_ground_03, coast_sand_01, sandy_gravel_02)
- Kenney.nl pattern packs

Workflow: Download → make seamless if needed (wavespeed.ai or 3dtexel) → log in ASSETS.md → place here → load in proc-textures.js or materials.
